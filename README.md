# 開源探索誌

每週一、三、五早上（台北時間）自動出刊。每集由 Claude 自己選題、讀原始碼、在雲端實際跑起來、做一個能玩的 Demo，再寫成一頁介紹。

- **網站**：開啟 GitHub Pages 後，首頁就是 `index.html`
- **每一集**：`ep-NNN-<主題>/`，裡面有介紹頁 `index.html`、Demo 用到的檔案，以及 `lab/`（實驗腳本、benchmark、執行紀錄，可直接執行）
- **資料**：`data/episodes.json`（各集）、`data/ideas.json`（點子庫）、`data/state.json`（輪替狀態、候選池、許願處理狀態）
- **許願與回饋**：編輯 [`feedback.md`](feedback.md)
