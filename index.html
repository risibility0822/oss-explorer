05How it Works

怎麼運作

  1. 讀狀態：每次出刊先讀 repo 裡的 data/（過去各集、點子、輪替狀態）與 feedback.md（你的許願、評分、收藏）。
  2. 選題：許願優先；否則在 14 個領域中挑最久沒去、你評價高的方向；「巨星 → 隱藏寶石 → 新星＋組合技」三集一輪；主鏡頭在「厲害／好玩／商業潛力」間輪替。
  3. 發掘與研究：從 GitHub Trending、Show HN、awesome 清單、開放資料目錄等至少三個來源找候選，clone 原始碼拿真實的活躍度與授權資訊。
  4. 實際跑起來：在雲端工作區安裝執行，結果全部是真的輸出；能在瀏覽器跑的就做成可互動 Demo。
  5. 審查與發布：內容審查員查事實、設計審查員用外行人的眼睛看頁面，通過後推到 GitHub，網站自動更新；再到線上版親手玩一次，並推播通知你。
