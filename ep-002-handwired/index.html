05Deep Dive

想深入再展開

原理細節比較器的公式、運算數的帳、為什麼弄亂會壞

運算數的帳：帳面上 1,416 個運算，真正在算的是 941 個 ReLU（負數變 0、正數照舊）和 7 個加減法；另外 468 個只是存著「3、6、9…」這類門檻數字（含一個 0），實際算時已經併進 ReLU 裡。每顆燈是兩個 ReLU 疊成：relu(1 − relu(門檻 − n))。

四個輸出由兩個「整除？」z3、z5 和 AND 的結果 A 加減組成：FizzBuzz＝A、Fizz＝z3 − A、Buzz＝z5 − A、數字＝1 − z3 − z5 + A，正好只有一個是 1。

對照：Joel Grus 那篇 2016 年玩笑文的 TensorFlow 訓練版，repo 裡 notebook 存下的一次結果答錯 4 題（4、23、49、53）。兩排燈裡 15 的倍數那 66 顆其實是同一批神經元，handwired 會自動共用。

handwired 的程式只有四種運算：加權和、ReLU 乘積（(a) × max(0, b)）、四捨五入成 0／1、查表。你寫的是「建構程式」：一段普通 JS，執行一次，把運算一個個加進 Circuit。執行期沒有任何分支或迴圈，所以 if 會變成兩邊都算再挑一邊，迴圈會變成固定數量的平行運算。

比較器 emitCompare(n, '>=', 3k) 在整數格點上只要 2 個運算：relu(1 − relu(3k − n))，n 跨過 3k 就剛好是 1。把 333 個比較器加起來就是 ⌊n/3⌋，這是它文件裡「threshold count」的寫法。其中 [n ≥ 15]、[n ≥ 30]… 這 66 個在兩排都會用到，handwired 建構時會認出是同一個運算而共用，所以實際是 333＋200−66＝467 個 ≥ 比較器，再加 2 個「餘數＝0」的比較器。因為所有東西都是加權和與 ReLU，整個程式可以反向傳播（backpropagateReference）；通用的 runtime 只在 CPU 上跑，作者的 JSON 搜尋 Demo 另外寫了產生器才跑在 WebGPU 上。

雜訊實驗會壞，是因為比較器的偏差值剛好卡在整數邊界：n 剛好等於 3k 時，3k − n 應該是 0；係數偏一點點它就變成很小的正數或負數，ReLU 的輸出不再是整數，後面的加總與餘數判斷就跟著錯。

五分鐘上手本集實際用的建構程式，可直接改成你的規則

handwired 沒有發佈到 npm，要 clone 下來直接 import src/runtime/。官方用 Bun；我們用 esbuild 打包也能在 Node 與瀏覽器跑。

import {createSourceTable, input, createEvaluator} from './runtime/cells.ts'
import {emitCompare} from './runtime/numeric-ui-core.ts'

const table = createSourceTable()
const cells = table.declare({n: input([1, 1000], {initial: 1, grid: 1})})
const circuit = table.createCircuit()
const c = v => circuit.constant(v)
// n % k === 0：先數 n 跨過幾個 k 的倍數，再算餘數
const divisible = k => {
  const bits = []
  for (let m = k; m <= 1000; m += k) bits.push([emitCompare(circuit, cells.n, '>=', c(m)), 1])
  const q = circuit.affine(bits); circuit.assumeRange(q, 0, Math.floor(1000 / k)); circuit.assumeGrid(q, 1)
  const r = circuit.affine([[cells.n, 1], [q, -k]]); circuit.assumeRange(r, 0, k - 1); circuit.assumeGrid(r, 1)
  return emitCompare(circuit, r, '===', c(0))
}
const d3 = divisible(3), d5 = divisible(5)
const fizzbuzz = circuit.reglu([], 1, [[d3, 1], [d5, 1]], -1)   // AND
const output = {fizzbuzz, fizz: circuit.affine([[d3, 1], [fizzbuzz, -1]])}
const built = {cells, output, ...table.finish()}
const evaluate = createEvaluator(built)

const src = new Float32Array(built.initialSource)
for (const n of [9, 15, 22]) {
  src[cells.n] = n
  console.log(n, evaluate(src).output)
}
// 實際輸出：9 { fizzbuzz: 0, fizz: 1 }、15 { fizzbuzz: 1, fizz: 0 }、22 { fizzbuzz: 0, fizz: 0 }

這段就是 lab/src/minimal.js，Demo 用的完整版在 fizzbuzz.ts 與 lab_run.ts。打包指令：npx esbuild minimal.js --bundle --platform=node --format=esm --outfile=minimal.mjs && node minimal.mjs。
