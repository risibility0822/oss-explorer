# SlideHelper 配色（精選 24 組）

- 2026-11-27 主人決定全面採用（取代和田三造《配色事典》）。
- 來源：SlideHelper「150 Custom Color Themes for MS Office」（主人提供的 XML 檔，每組取 accent1–5 共 5 色）。
- **只收錄主人選用的組合，不是整包**：套件沒有附授權條款，部分組合與 Coolors 熱門配色相同（Coolors 條款不允許整批散布），所以 repo 只放實際要用的色碼。要加新的組合，從主人的 XML 檔挑，補進 palettes.json。
- 頁面註明「配色：參考 SlideHelper 配色第 N 組」。
- 只能由 `oss.py palette` 讀取；不要手改。
